# Font terbundel

## Inter Tight (font tampilan, sejak ronde 8089)

- Berkas: `InterTight-Medium.ttf` (500), `InterTight-SemiBold.ttf` (600),
  `InterTight-Bold.ttf` (700) — instance statis latin + latin-ext,
  diekstrak dari variable font resmi dengan fontTools.
- Sumber: Google Fonts — repo `google/fonts` (`ofl/intertight`,
  `InterTight[wght].ttf`), diunduh 2026-11-25.
- Lisensi: SIL Open Font License 1.1 (OFL-1.1) — gratis untuk pemakaian
  personal & komersial, termasuk dibundel ke aplikasi.
- Keputusan pemilik 2026-11-25: Inter Tight menggantikan Clash Display
  (Fontshare) sebagai font tampilan Clai, lewat spesimen berdampingan.
  Inter tetap untuk isi/label. Bobot peran utama (displayStyle/heroStyle)
  naik ke 700; bobot 600 tetap terdaftar untuk pemetaan 1:1 non-utama
  (kartu QR bagikan).
